API Kết nối tới Apps Script Proxy

Chi tiết kỹ thuật & hướng dẫn cài đặt (bấm để xem)

Xem hướng dẫn cài đặt đầy đủ ở đầu file Code.gs: tạo project Apps Script → dán code → lưu khóa Gemini vào Script Properties (không lưu trong HTML) → Deploy dạng Web App → dán URL vào đây. Model dùng ở backend là gemini-2.5-flash (và các model dự phòng cùng dòng) — theo trang giá chính thức của Google (ai.google.dev/gemini-api/docs/pricing, cập nhật 2026‑06‑30), đây là các model duy nhất trong dòng miễn phí hiện có Google Search grounding miễn phí (500 request/ngày dùng chung).

Trang này gọi Apps Script bằng kỹ thuật JSONP (thẻ <script>) thay vì fetch(), để tránh lỗi CORS thường gặp khi gọi Apps Script Web App bằng POST từ trình duyệt.
